# Tama Arts — Premium E-Commerce Platform

## Tech Stack
- Next.js 16.2.4 (App Router) + React 19 + TypeScript
- Auth: Clerk
- Database: Supabase (PostgreSQL) + Prisma 7.8.0 ORM
- Payments: Midtrans Snap
- State: Zustand
- Styling: Tailwind CSS 4.2.4
- Testing: Vitest + React Testing Library

## Purpose
Full-stack e-commerce platform for selling premium artisan clothing with complete shopping flow + admin suite.

## Key Features
**Customer:** Product grid with variant switching, real-time stock, cart, Midtrans checkout
**Admin:** Sales analytics, user management (RBAC), product CRUD, order tracking, dynamic site settings, page content

## Data Models
User, Transaction, TransactionItem, Product, ProductVariant, ProductImage, Visit, SiteSettings, PageContent
